# 智能问询笔录平台 - 页面原型图

## 📁 文件说明

- **智能问询笔录平台-原型图.pen** - pen.dev 格式的原型图文件
- **prompt** - 设计需求和页面描述文档

## 🎨 包含的页面

本原型图包含 6 个核心页面 + 1 个索引导航页：

### 1. UI-1: 登录与工作台首页
- 现代化登录界面（账号密码/扫码/短信登录）
- 工作台仪表盘（案件统计、快速操作入口）
- 待办事项和通知中心

### 2. UI-2: 案件基础信息采集页
- 三栏布局设计
- 左侧：基础信息表单（案件编号、类型、当事人信息等）
- 中间：实时同步面板（数据校验和保存状态）
- 智能字段校验和提示

### 3. UI-3: 问询模板智能匹配页
- AI 智能推荐模板（带匹配度评分）
- 推荐理由和适用场景说明
- 全量模板库浏览（按案件类型分类）
- 模板预览和快速启用功能

### 4. UI-4: 三栏沉浸式问询工作台（核心页面）
- **左栏**：模板问题引导区（问题列表、进度追踪）
- **中栏**：核心对话记录区（实时语音识别、文本输入）
- **右栏**：五流证据管理区（资金流、信息流、货物流、人员流、技术流）
- 证据分类上传和预览功能

### 5. UI-5: 实时笔录生成与编辑页
- 富文本编辑器（AI 辅助工具：智能纠错、法律术语）
- 左侧工具栏（格式化、段落调整）
- 右侧信息面板（生成时间、质量评分、版本历史）
- 快速导出（Word/PDF）

### 6. UI-6: 历史笔录导入与回溯页
- 左侧筛选面板（案件类型、时间范围、笔录状态）
- 右侧笔录列表（卡片式展示、状态标识）
- 高级搜索功能
- 批量操作和导出功能

### 7. 索引页：页面总览导航
- 所有页面的缩略图展示
- 设计完成度统计
- 快速导航功能

## 🎨 设计规范

### 配色方案
- **主题**：深色主题（专业、适合长时间工作）
- **主色调**：蓝色系（#3B6DFF, #38BDF8）
- **背景色**：多层次深色背景（#05070C → #1E2636）
- **文字颜色**：白色系层级（主文字/次要文字/提示文字）
- **状态色**：
  - 成功：绿色（$success）
  - 警告：橙色（$warning）
  - 错误：红色（$error）

### 设计尺寸
- **标准分辨率**：1920×1080
- **组件化设计**：所有元素都可复用
- **响应式支持**：适配不同屏幕尺寸

### 图标系统
- **图标库**：Material Symbols Rounded
- **统一风格**：圆角、一致的视觉重量

## 💻 后续开发建议

### 前端技术栈推荐
- **框架**：React 18+ / Vue 3+
- **UI 组件库**：Ant Design / Element Plus / shadcn/ui
- **样式方案**：Tailwind CSS / CSS Modules
- **状态管理**：Zustand / Pinia
- **富文本编辑器**：Quill / TipTap / Slate

### 开发流程
1. **设计审核**：团队评审原型图，确认交互流程
2. **组件拆分**：将页面拆分为可复用组件
3. **样式提取**：建立设计 Token 系统（颜色、间距、圆角等）
4. **API 对接**：根据页面功能设计后端接口
5. **逐页开发**：按照页面优先级依次实现
6. **集成测试**：完整流程测试和用户体验优化

### 优先级建议
1. **P0**：UI-1（登录）、UI-4（问询工作台）
2. **P1**：UI-2（信息采集）、UI-5（笔录编辑）
3. **P2**：UI-3（模板匹配）、UI-6（历史管理）
